# Week 2 Reflection
## Process Model Selection

For a student study-planner app, I would use the incremental process model. The first version could include basic features such as creating tasks, setting deadlines and viewing a weekly schedule. More features could then be added over time.

I think the incremental model would suit this project because the requirements could change once students begin using the app. Releasing a basic version early would allow students to give feedback about what works well and what could be improved. Features such as notifications, calendar integration and study groups could then be added in later versions.

There would be relatively low safety risk, so releasing the software in stages would be suitable. It would also allow development to begin without every feature being fully planned from the start. One risk is that continuously adding new features could lead to scope creep and make the project more difficult to manage.
